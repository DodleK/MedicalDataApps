# 🏥 Medical Data Management System

## 🚩 Problem Statement

In many clinics and healthcare facilities, managing patient records, doctor assignments, appointments, and prescriptions is still handled manually or through outdated software. This leads to:

- **Inefficient record keeping**  
- **Human errors in scheduling or medication tracking**  
- **Poor data visibility for medical trends and reporting**  
- **Scattered or inaccessible information for doctors and staff**

Modern healthcare systems need a centralized, digital solution that simplifies data management and enables seamless access to critical medical information.

## ✅ Solution Overview

The **Medical Data Management System** is a full-stack application that addresses these issues by digitizing and organizing healthcare data in a relational database with an intuitive web interface. It allows medical staff to efficiently perform CRUD operations, generate reports, and visualize trends in appointments and prescriptions.

Built with **ASP.NET Core (C#)** for the frontend and **Microsoft SQL Server** for the backend, this system is scalable, secure, and ready for real-world healthcare environments.

---

## 🔧 Features

- 📁 Manage **Patients**, **Doctors**, **Appointments**, and **Medications**  
- 🔄 Full **CRUD operations** with automatic data validation  
- 📊 SQL-based **report generation** and trend analysis  
- 🌐 Responsive web UI with MVC architecture  
- ⚙️ Easy integration with other healthcare systems or tools

---

## 🧱 Tech Stack

- **Frontend:** ASP.NET Core MVC  
- **Backend:** C#, Entity Framework Core  
- **Database:** MS SQL Server  
- **Tools:** Visual Studio, SSMS, NuGet, LINQ

---

## 📂 Project Structure

The project is broken down into 10 steps:

1. **Environment Setup** – Install SQL Server, Visual Studio, and required tools  
2. **Database Design** – Create tables for core entities and import datasets  
3. **Backend Queries** – Test SQL scripts for real-world data use cases  
4. **ASP.NET Project Setup** – Create the MVC web application  
5. **Entity Framework Integration** – Setup DbContext and configure models  
6. **Model Creation** – Define data models with navigation properties  
7. **Database Migrations** – Use EF Core to sync models to SQL Server  
8. **Scaffold Views & Controllers** – Auto-generate full-featured pages  
9. **Frontend Customization** – Edit homepage and navigation for usability  
10. **Application Launch** – Build and run the web app
